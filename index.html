Executive Key Takeaways

  • 01
    Authentication Landscapes 70% of audited applications implement OAuth2. While API keys (54%) and plain Tokens (37%) are widely available, OAuth2 is mandatory for any enterprise-grade deployment due to security constraints.
  • 02
    Self-Serve Gating Divergence Modern developer platforms (Vercel, Supabase) and productivity suites are fully self-serve. Fintech (Brex, Ramp) and enterprise sales CRM (DealCloud) require corporate domain verifications or sales contact.
  • 03
    Friction Blockers Identified Google Ads, Meta Ads, and LinkedIn Ads require formal App Audits and organization verifications. Building automated tool call pipelines for these requires navigating multi-week manual review queues.
  • 04
    Realistic MCP Server Mapping Out of 100 audited SaaS applications, only 14% (14 apps) have real, verified Model Context Protocol (MCP) servers (e.g. GitHub, Supabase, Linear, Stripe). The remaining 86% require raw API connectors.
